VERSI 1.0.3 — Build terbaru (25 Agustus 2026)
----------------------------------------------------------------------

Catatan rilis untuk Play Console (salin teks ini):

"Update stabilitas dan kepatuhan Play Store terbaru:
• Target Android 16 (API 36) dan dukungan perangkat Android 6.0+ (minSdk 23)
• Penarikan saldo kini nyata: koin terpotong otomatis, tercatat di riwayat
  transaksi dengan status yang bisa dipantau
• Perbaikan tampilan daily reward dan area tambang berikutnya
• Perbaikan bug dan peningkatan performa"

Detail teknis build ini:
- Package       : com.altomedia.indomine
- Version name  : 1.0.3
- minSdk        : 23
- targetSdk     : 36 (persyaratan Play Console terkini; API 37 belum
                  didukung toolchain build saat ini)
- Signing       : keystore ALTOMEDIA.jks (alias kdsmedia)
- Build system  : EAS Build (Expo)

Perbaikan & perubahan di versi ini:
1. FIX: Penarikan wallet bukan lagi stub — sekarang benar-benar memotong
   koin, memvalidasi nomor DANA, dan mencatat transaksi WITHDRAWAL
   berstatus pending untuk diproses admin.
2. FIX: Saldo "Pending" di wallet dihitung dari transaksi penarikan
   pending, bukan angka hardcoded.
3. FIX: Preview reward pada DailyRewardModal konsisten dengan logika
   streak (tercap di hari ke-7).
4. FIX: Kartu "Area Berikutnya" memakai total koin yang diperoleh secara
   konsisten dengan progress bar.
5. FIX: Duplikasi kode dan import dibersihkan; seluruh warning lint
   dihilangkan (0 error, 0 warning).
6. BUILD: Downgrade react-native-google-mobile-ads ke 15.0.0 (GMA SDK
   24.1.0) agar kompatibel dengan toolchain Kotlin 2.0.
7. BUILD: AdMob App ID resmi dikonfigurasi langsung di AndroidManifest.
8. BUILD: Migrasi pnpm ke npm agar EAS Build stabil.

VERSI 1.0.2 (24 Agustus 2026)
----------------------------------------------------------------------

- Perbaikan import AdBanner yang hilang di halaman Mining.
- Perbaikan cabang misi kedaluwarsa yang mereferensikan handler
  tidak terdefinisi.
- Penghapusan konstanta penarikan usang di halaman Wallet.
- Nama aplikasi resmi INDOMINE di layar masuk.
- Ikon koin seragam di seluruh tampilan.
- Teks tombol & menu diperpendek.
- Mining diperlambat dengan algoritma SHA-256 + tampilan hash rate.
- Mining wajib internet; berhenti otomatis saat offline/aplikasi ditutup.
- Statistik mining 3 kartu mini sebaris.
- Misi tampil 2 kartu sebaris dengan tombol sesuai tugas.
- 10 paket upgrade.
- ID user/referral 6 digit dari nomor ponsel.
- Kontak admin tanpa email di UI; tombol WhatsApp ikon + teks.
- Fitur achievement dihapus.
- Syarat penarikan: saldo min Rp1.000 + 350 sesi bonus.
